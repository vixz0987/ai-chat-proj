# Генератор синтетического датасета

Вспомогательный инструмент для генерации синтетических данных с целью первоначального обучения и тестирования модели машинного обучения для профориентационного чат-бота.

Генератор используется на этапе разработки, пока отсутствует достаточное количество реальных диалогов с абитуриентами. Полученные данные имитируют ответы пользователей на вопросы чат-бота и позволяют проверить работу модели классификации.

## Структура проекта

```text
ai-chat-proj/
├── data/
│   ├── question_ script.xlsx
│   └── proforient_train_dataset.csv
├── generator/
│   └── generator.py
├── pyproject.toml
├── uv.lock
└── README.md
```

- `question_ script.xlsx` — сценарий чат-бота: вопросы, варианты ответов и баллы по профориентационным кластерам.
- `generator.py` — скрипт генерации датасета.
- `proforient_train_dataset.csv` — сгенерированная обучающая выборка.

## Формат данных

Каждая строка датасета представляет одного условного абитуриента.

Датасет содержит не более 50 признаков:
- ответы на вопросы с одиночным и множественным выбором;
- числовые ответы на вопросы со шкалой;
- признаки `kw_K1–kw_K12` — количество срабатываний ключевых слов для каждого кластера;
- маршрут прохождения опроса (`path`).

Целевая переменная `target_cluster` определяет основной кластер интересов абитуриента (K1–K12).

## Принцип генерации

Данные формируются на основе сценария опроса из Excel-файла.

Для каждого респондента:
1. Случайным образом определяется основной кластер интересов и, с некоторой вероятностью, дополнительный.
2. Выбирается один из четырёх маршрутов прохождения опроса: `FULL`, `SHORT`, `KNOWN` или `BROWSE`.
3. Генерируются ответы на вопросы с учётом баллов вариантов по кластерам, индивидуальных интересов и случайного шума.
4. Для вопросов со свободным вводом имитируется анализ ключевых слов. Результаты сохраняются в признаках `kw_K1–kw_K12`.

Таким образом, ответы одного респондента связаны между собой и отражают заданный профиль интересов, а не генерируются полностью независимо.

## Установка и запуск

**Требования:** Python 3.12+, [uv](https://docs.astral.sh/uv/).

Клонирование репозитория:

```bash
git clone https://github.com/vixz0987/ai-chat-proj.git
cd ai-chat-proj
```

Установка зависимостей:

```bash
uv sync
```

Запуск генератора:

```bash
uv run python generator/generator.py
```

По умолчанию генерируется 5500 строк с сохранением результата в `data/proforient_train_dataset.csv`.

### Параметры запуска

| Аргумент | Назначение |
|---|---|
| `--n` | Количество генерируемых строк (не менее 5000) |
| `--out` | Путь к выходному CSV-файлу |
| `--xlsx` | Путь к Excel-файлу со сценарием |
| `--check` | Дополнительная проверка качества данных с помощью базовой ML-модели |

Пример генерации 10000 строк:

```bash
uv run python generator/generator.py --n 10000
```

Запуск с дополнительной проверкой:

```bash
uv run python generator/generator.py --check
```

## Проверка данных

После генерации выполняются проверки:
- минимального количества строк;
- количества признаков (не более 50);
- распределения целевых кластеров;
- отсутствия полностью дублирующихся строк.

При использовании `--check` дополнительно обучается базовая модель классификации `HistGradientBoostingClassifier`. Выводятся метрики Accuracy и Top-3 Accuracy, позволяющие оценить, насколько хорошо модель восстанавливает целевой кластер по сгенерированным ответам.

## Примечание

Датасет является синтетическим и предназначен исключительно для первоначального обучения, тестирования и отладки модели. Полученные результаты не гарантируют аналогичного качества на реальных данных.

По мере накопления диалогов с абитуриентами синтетическую выборку необходимо дополнить реальными ответами и проверенной разметкой.
